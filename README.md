# Девять автономных вариантов сайта ЦДО СГУПС

Предпросмотр на Render из **статических копий**. После архивации Render **не обращается к arena.site** при посещении вариантов. Сохранены HTML/CSS/JS и требуемые сторонние шрифты.

## Работа сайта

- `/` — выбор варианта.
- `/review?v=1` — просмотр варианта и переключение 01–09.
- `/?__arena_variant=1` — прямая ссылка на сохранённую копию.
- `/assets/...` — локальные шрифты и файлы.
- `/healthz` — проверка работы сервера.
- `/cdn-cgi/rum` — пустой ответ для устаревших телеметрических запросов из кеша браузера.

## Развёртывание на Render

Подключите этот репозиторий через **New → Blueprint**, как и прежде: `render.yaml` содержит команду сборки Go-сервера, никакого обращения к Arena при сборке/старте Render не требуется. Не нужен ни VPS, ни собственный домен. Бесплатный Render может засыпать после бездействия.

## Откуда берутся копии

Копии сохранены в `snapshots/1.html` … `snapshots/9.html`, медиа и шрифты — в `snapshots/assets/`. `snapshots/manifest.json` хранит контрольные суммы и дату создания.

Если понадобится обновить варианты:

1. В GitHub откройте **Actions → Archive Arena variants (one-time / manual) → Run workflow** для ветки `main`.
2. Сборщик `scripts/archive_sites.py` скачает актуальные версии с Arena и запишет в Git репозиторий, после чего Render сможет задеплоить новый коммит.
3. Если исходник недоступен или вернулась страница-обёртка вместо сайта, задача остановится с ошибкой, не выдавая сломанную копию за корректную.

**Внимание:** не запускайте обновление, если хотите сохранить именно текущий вариант — после изменений в Arena архив тоже изменится. Для первоначального развёртывания никакой синхронизации не требуется.

## Ограничения

- Это автономные *снимки сайтов*, а не исходные проекты с редактором и серверными API.
- Внутренние интерактивные элементы, не требующие внешних API, работают как и раньше. Ссылки на сайты университета, соцсети и другие внешние сервисы по-прежнему открывают соответствующие сайты.
- Если встраиваемый исходник позже начнёт обращаться к внешнему API, для полной офлайн-независимости потребуется отдельно сохранить данные либо заменить такой вызов.
- `go test ./...` проверяет доступность 9 копий, их содержимое, сохранённые ресурсы, отсутствие проксирования, обработку маршрутов и телеметрии.

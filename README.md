# Arena variants — бесплатный прокси для Render

Никакого VPS, домена, Docker, базы или переменных окружения.

## Как запустить

1. Создай пустой репозиторий на GitHub и загрузи туда эти файлы.
2. Открой https://dashboard.render.com/ и нажми **New → Blueprint**.
3. Подключи репозиторий. Render сам увидит `render.yaml`.
4. Нажми **Apply**.

После деплоя получишь HTTPS-ссылку вида:

`https://arena-variants-xxxx.onrender.com`

Её и отправляешь заказчику.

## Что внутри

- 9 вариантов на одной странице;
- переключение между ними;
- Arena грузится сервером Render;
- у клиента нет прямой необходимости открывать `arena.site`;
- кнопка «Выбрать вариант» копирует номер;
- нет базы/регистрации/админки.

## Ограничение Render Free

После 15 минут без запросов бесплатный Web Service засыпает. Первый запрос после сна может запускаться заметно дольше обычного.
